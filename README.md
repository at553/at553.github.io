# at553.github.io

Personal GitHub Pages site for Avinash Thangali.

## Local Preview

This is a static site. Open `index.html` directly in a browser, or run:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Structure

- `index.html` contains the page content and metadata.
- `css/grayscale.css` contains the custom responsive styles.
- `img/me.jpg` is the profile image used on the page and in link previews.
- `.nojekyll` tells GitHub Pages to serve the repo as plain static files.
